# B.Ed / ADE Pedagogy — Knowledge Pack

The vocabulary a Pakistani teaching-practice supervisor expects to see. Use these terms
by name; an unnamed method reads as an unplanned lesson.

## Teaching methods

| Method | Use it when | Looks like |
|---|---|---|
| Lecture / exposition | dense factual content, short bursts only | teacher input, max 8–10 min |
| Demonstration | a procedure or skill | teacher does, narrates, students copy |
| Inductive | a rule can be discovered | examples first, rule named last |
| Deductive | a rule must be applied fast | rule first, then practice |
| Inquiry / discovery | a question can drive it | question, hypothesis, test, conclude |
| Activity-based | concrete concept, young learners | manipulatives, sorting, building |
| Cooperative learning | practice with talk | Think-Pair-Share, Jigsaw, Numbered Heads Together, Round Robin |
| Problem solving | application stage | given problem, strategy, check |
| Role play / simulation | social, historical, language | assigned roles, short script |
| Storytelling | primary, moral, historical | narrative hook then extraction |
| Project based | multi-lesson | brief, milestones, product |
| Direct instruction (I do / We do / You do) | skills and procedures | gradual release |

## Herbartian steps (still named on Pakistani B.Ed formats)

1. Preparation / Introduction — link to prior knowledge
2. Presentation — new material
3. Comparison and Association — relate to the known
4. Generalisation — arrive at the rule
5. Application — use the rule on new cases
6. Recapitulation — check retention

## 5E (Cambridge and science-heavy plans)

Engage → Explore → Explain → Elaborate → Evaluate

## Gradual release

**I do** (model aloud) → **We do** (guided, teacher still in the loop) → **You do**
(independent, teacher circulates and records who is stuck).

## Domains of objectives

- **Cognitive** (Bloom) — knowledge and thinking
- **Affective** (Krathwohl) — receiving, responding, valuing, organising, characterising.
  Phrase as: "shows willingness to ...", "volunteers ...", "listens without interrupting"
- **Psychomotor** (Dave) — imitation, manipulation, precision, articulation,
  naturalisation. Phrase as: "draws a labelled diagram to scale", "handles the beaker"

Every plan should carry at least one affective or psychomotor line in Skills / Attitude.

## Classroom management — rules

Write rules **positively**, 4 to 5 maximum, visible, and taught not announced:
- "We raise a hand before speaking."
- "We listen when a classmate is answering."
- "We keep our books and desk ready before the bell."
- "We move to group seats quietly, in ten seconds."

## Classroom management — strategies

Name the actual technique:
- **Attention signal** — clap pattern, "eyes on me / eyes on you", countdown from five
- **Proximity** — teacher moves to the disengaged learner rather than calling them out
- **Non-verbal cues** — pause, look, gesture
- **Wait time** — three to five seconds after a question before taking any answer
- **No hands up / cold call** — names drawn from lollipop sticks so all stay ready
- **Positive narration** — praise the behaviour you want, by name
- **Transitions timed aloud** — "you have ninety seconds"
- **Seating plan** — struggling learners near the front and beside a supportive peer
- **Group roles** — leader, writer, timekeeper, reporter, so no one hides

## Assessment for Learning (AfL) techniques

Fast, whole-class, evidence-gathering:
- Thumbs up / sideways / down
- Mini whiteboards or slates, all show together
- Traffic-light cards or coloured cups
- Exit ticket (one question on a slip, collected at the door)
- Hinge question — one MCQ mid-lesson whose answer decides what happens next
- Cold call with wait time
- Show me on fingers (1 to 5)
- Two stars and a wish (peer feedback)
- Think-Pair-Share, then the teacher samples three pairs

## Differentiation

Same objective, different route. Always give all three:
- **Support** — a worked example on the desk, sentence starters, a partly completed
  table, a word bank, a peer partner, fewer but not easier items, teacher at that table
- **Core** — the main task
- **Extension** — a why question, a second representation, a "now make one for a friend",
  an error-finding task, a real-world transfer

Never extend by "give more of the same sums".

## Teaching aids (low-cost, Pakistan-appropriate)

Chart paper, flashcards, real objects (fruit, coins, bottle caps, stones, leaves,
matchboxes), a number line drawn on the floor with chalk, cut-out shapes from old
cartons, a balance made from a hanger, string, newspaper, the blackboard itself, the
classroom window, learners' own bodies, and the textbook. Name the aid *and* what it is
used for; a list of nouns is not a resource section.

## Board work

The board summary is the child's copy. Plan it as it will physically appear: heading,
the key terms with definitions, the worked example, the rule in a box, the homework in
the bottom corner. A supervisor reads the board plan to judge whether the lesson has a
spine.

## Homework

Short, doable without a parent's help, tied to today's objective, and markable in under
a minute per child. State how it will be checked next lesson.
