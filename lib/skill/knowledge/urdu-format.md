# سبقی خاکہ — Urdu Lesson Plan Knowledge Pack

When the teacher chooses Urdu output, the whole plan is written in Urdu, using the
section names of the standard Pakistani B.Ed سبقی خاکہ. Do not translate an
English-shaped plan word by word; write it the way Urdu-medium teacher-training
documents are actually written.

## Section names and what belongs in each

| Field | اردو عنوان | Content |
|---|---|---|
| lessonNo | سبق کا نمبر شمار | number only |
| date | تاریخِ تدریس | date |
| grade | جماعت | class |
| section | فریق | section |
| averageAge | اوسط عمر | average age in years |
| duration | دورانیۂِ تدریس | minutes |
| subject | مضمون | subject |
| topic | عنوان | the topic |
| coreSkill | سبق کی بنیادی مہارت | the one core skill: سننا، بولنا، پڑھنا، لکھنا، تنقیدی سوچ، تخلیقی اظہار |
| teacher | معلم / معلمہ | teacher's name |
| objectives | مقاصدِ تدریس | 3–5 measurable objectives |
| classroomRules | اصول و ضوابط برائے منظم کمرۂِ جماعت | positively phrased rules |
| managementStrategies | حکمتِ عمل برائے منظم کمرۂِ جماعت | named management techniques |
| avAids | سمعی و بصری اعانات | audio-visual aids |
| method | طریقۂِ تدریس | the named teaching method |
| contentDelivery | ترسیلِ مواد (جُز / جُزو) | how the content is broken into parts |
| coreConcept | سبق کا بنیادی تصور | the single central idea of the lesson |
| initiation | ابتدائی سرگرمی | warm-up activity |
| announcement | اعلانِ سبق | how the topic is announced to the class |
| activities | سرگرمی نمبر ۱، ۲، ۳ | numbered main activities |
| boardSummary | خلاصۂِ تختۂِ سیاہ / اعادہ | board summary and recap |
| evaluation | جانچ | assessment questions with marks |
| homework | تفویض | homework |
| coTeacherFeedback | معاون معلم / معلمہ کے تاثرات | left blank for the co-teacher |
| supervisorFeedback | نگراں معلم / معلمہ کے تاثرات | left blank for the supervisor |

The two feedback fields are filled by a human, never by the model. Emit them as an empty
line so the printed sheet leaves writing space.

## Objective grammar in Urdu

    سبق کے اختتام پر طلبہ [شرط] [قابلِ پیمائش فعل] سکیں گے، [معیار]۔

Example:
    سبق کے اختتام پر طلبہ دیے گئے پیراگراف میں سے کم از کم پانچ اسم صفت الگ کر کے
    لکھ سکیں گے۔

بیان کر سکیں گے، لکھ سکیں گے، شناخت کر سکیں گے، الگ کر سکیں گے، درجہ بندی کر سکیں گے،
موازنہ کر سکیں گے، حل کر سکیں گے، وجہ بتا سکیں گے، مثال دے سکیں گے، خاکہ بنا سکیں گے،
جملے بنا سکیں گے، ترتیب دے سکیں گے، نتیجہ اخذ کر سکیں گے، دلیل دے سکیں گے،
تخلیق کر سکیں گے، تلفظ کے ساتھ پڑھ سکیں گے

## Banned in Urdu objectives
سمجھ سکیں گے، جان سکیں گے، واقف ہو سکیں گے، آگاہی حاصل کر سکیں گے، معلومات حاصل کر سکیں گے

(These are not observable. Same rule as English.)

## Urdu-subject specific notes

For the subject اردو itself, the four مہارتیں drive planning:
سننا (listening), بولنا (speaking), پڑھنا (reading), لکھنا (writing).
Grammar topics commonly planned: اسم، فعل، حرف، صفت، ضمیر، واحد جمع، مذکر مؤنث،
متضاد، مترادف، محاورے، ضرب الامثال، تلخیص، مضمون نویسی، خط نویسی، روزنامچہ.
Literature: نظم، غزل، حمد، نعت، کہانی، سبق، مکالمہ.

## Register

Use formal academic Urdu with correct اضافت where it belongs (دورانیۂِ تدریس،
کمرۂِ جماعت، مقاصدِ تدریس، خلاصۂِ تختۂِ سیاہ). Keep numerals in the form the school uses;
Urdu numerals (۱، ۲، ۳) for activity numbering is standard. Write the plan as instructions
to the teacher, in the same directness as the English version.
